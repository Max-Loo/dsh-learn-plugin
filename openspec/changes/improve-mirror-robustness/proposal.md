# Proposal

## Why

调研发现的六个中等级健壮性/语义问题：镜像模块四个进程内集合（`links`、`knownUnlinked`、`askedQuiz`、`callMeta`）只增不减，长驻宿主中无界增长；`lesson_log` 链接建立期间（回填读取到链接生效之间）到达的实时事件被静默丢弃，且竞态可触发伪 "restored" 注记；每次会话恢复都向课程文件追加一条恢复注记，随重启次数累积污染学习记录；解除后重链同一文件会把全部历史重复回填一遍；quiz 面板被跳过（未选任何选项、无自定义答案）时被判定为 `incorrect ✗`，与"猜错"混淆，误导教学摸底；graded-quiz spec 的答案不泄漏 requirement 承诺"不出现在包括转录在内的任何用户可见界面"，超出插件可执行的边界（原始调用参数由平台持久化，插件只能约束自己渲染的界面），承诺面与保障面不一致。这些不至于破坏数据，但持续损耗日志质量与判定语义，值得一批次集中治理。

## What Changes

- 镜像状态治理：进程内链接/去重集合按会话生命周期清理，宿主长期运行不再无界增长（`callMeta` 按会话+上限收敛）。
- 链接建立无缝衔接：链接过程中到达的实时事件进入暂存，链接生效后按序补镜像，不再丢失；消除该窗口内触发伪恢复注记的竞态。
- 恢复注记降噪：同一链接的恢复注记至多写入日志一次（持久化标志），后续重启不再追加。
- 重链去重：解除后重链同一文件时从既有镜像水位续传，不重复回填已镜像内容。
- quiz 跳过语义：面板跳过（空选且无自定义答案）SHALL 归入"未作答"信号通道（同 "I don't know"：非对非错、不显 ✗、揭示正确答案），不再判定为错误。
- 答案不泄漏措辞对齐：spec 承诺收敛到插件可控的呈现面（工具卡片、作答面板、判定前反馈不泄漏），不再宣称约束平台持久化存储本身。

实施与归档顺序依赖 `harden-lesson-log`（本变更的「链接恢复」delta 基于其归档后的水位语义文本；重链去重亦复用其持久化水位）。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `lesson-log`: 「历史回填」增加链接窗口事件不丢失与重链同一文件不重复回填；「链接恢复」增加恢复注记至多一次的降噪约束。
- `graded-quiz`: 「答案不泄漏」承诺面收敛到插件控制的呈现；新增「跳过信号」requirement（空答归入未作答通道）。

## Impact

- `src/log.ts`：`linkSession` 重排为占位-回填-放行三段式；`linkFor` 恢复注记一次性标志；重链路径读取既有水位；状态集合清理（会话结束钩子/上限）。
- `src/quiz.ts`：`execute` 判分分支——空选且无自定义答案映射为未作答信号（`status: 'dontKnow'` 通道，反馈与结构化结果注明 skipped）；工具描述同步。
- `client/index.js`：判定卡对跳过场景的呈现（无 ✗、正确答案揭示）——复用 dontKnow 分支，无需结构改动，需验证覆盖。
- 存储域：link record 增加恢复注记标志字段（跟随 `harden-lesson-log` 的 v2 schema，在其归档后扩展为 v2 内新增可选字段）。
- 测试：`test/log-harness.ts` 增加窗口不丢事件、重链不重复、注记一次断言；`test/quiz-harness.ts` 增加跳过场景断言。
- spec 措辞：graded-quiz「答案不泄漏」requirement 文本修订（行为不变，承诺面收敛）。
